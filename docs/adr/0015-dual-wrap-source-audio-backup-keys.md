# Dual-wrap Source Audio Backup keys

Each Source Audio Backup uses a unique authenticated-encryption data key that is wrapped twice: once with the public half of an RSA-4096 AWS KMS key in a dedicated Cauli account in `us-east-2` using RSA-OAEP-SHA256, and once to an offline `age` X25519 recipient using the standard age format. The operator will create a new AWS account used exclusively for Cauli, secure its root account with a unique email, unique password, and MFA, add billing alerts, and create no root access keys before an implementation agent receives narrowly scoped provisioning authority. The worker holds only public material and no AWS credential, the normally disabled MFA-protected restore role may call KMS decryption only during an audited recovery, and the passphrase-encrypted age identity is never stored in Railway, Supabase, the VPS, Sentry, GitHub, or Peely; sealed Copy A is kept at the operator’s residence and sealed Copy B in the partner’s office safe, while the password-manager emergency kit remains separate from both. An offline restore is proven using the official age CLI before launch, after rotation, and annually while KMS restores are drilled quarterly. Either recovery path can restore a backup, old wrapping-key versions remain available until every dependent backup expires or is verified as rewrapped, and suspected key exposure requires rotation and rewrapping of every unexpired backup.
