# Use content-scrubbed managed Sentry

Cauli will use a new dedicated Cauli-owned Sentry organization on Sentry’s free U.S.-region Developer plan. The operator will be its sole initial owner and will create and secure the account with verified email, a unique password, and MFA before providing narrowly scoped configuration credentials to implementation agents. The organization will contain separate web and worker projects, with production and staging environments, private source maps, and a same-origin browser tunnel. Error reporting and critical traces are retained for the plan’s 30-day lookback, while Session Replay, attachments, feedback, profiling, log ingestion, Seer, request bodies, default PII, and other content-bearing features remain disabled; routine high-volume work is sampled or excluded so telemetry stays within the free quota and Cauli continues normally if Sentry is unavailable.
