# Prohibit unapproved regulated workloads

The controlled pilot has factual security controls but no independent certification or specialized regulated-use assessment. Cauli will contractually prohibit Workloads requiring an unaccepted regulatory, certification, residency, or security regime, require the initial Admin to accept that boundary, and avoid claims such as SOC 2, ISO 27001, HIPAA, PCI DSS, FedRAMP, or GDPR compliant or ready; product and security materials may describe implemented controls without implying an assessment that did not occur.
