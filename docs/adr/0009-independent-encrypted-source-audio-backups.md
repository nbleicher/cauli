# Independent encrypted Source Audio backups

Supabase database backups do not contain Storage objects, so Source Audio requires a separate recovery path. Cauli will copy each Source Audio object to an always-on VPS whose provider, region, and credentials are independent of Supabase and Railway, then copy the encrypted backup to Peely SSD as an additional offline copy. Backup payloads use per-Call authenticated encryption with keys wrapped by a versioned master key that is never stored on either backup target; object names are opaque and manifests are encrypted so backup metadata does not expose Workspace or Call information. Application credentials may create but not overwrite or delete immutable backups; a separately authorized retention process applies manual deletion and the Workspace Retention Policy. VPS backup has a 15-minute recovery-point target without gating Call readiness and a four-hour recovery-time target with checksum and authentication verification. Peely synchronizes and verifies encrypted VPS backups daily and alerts after 48 hours without a successful sync.
